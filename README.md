# 今日のToDo

HTML・CSS・JavaScriptだけで動作する、日本語のToDoリストです。

## 使い方

ChromebookのChromeで `index.html` を開きます。CSSとJavaScriptを内蔵しているため、このファイルだけで動作します。インストールやビルドは不要です。

- タスクを入力し、「追加」またはEnterキーで追加します。
- チェックボックスで完了・未完了を切り替えます。
- 「削除」でタスクを削除します。

タスクはブラウザのlocalStorageに保存されます。同じブラウザ・同じ場所で開くと復元されます。ブラウザのデータ削除やシークレットモードでは保存が失われる場合があります。端末間の同期機能はありません。

必要に応じて、このディレクトリで `python3 -m http.server 8000` を実行して配信できます。外部ライブラリやネットワーク接続は不要です。
